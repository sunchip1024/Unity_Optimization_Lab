# 04 — 필살기 화면 효과가 GPU를 지연

## 개발 상황과 증상

필살기 사용 시 화면 전체에 신비한 왜곡 효과를 적용했다. CPU 게임 로직은 가볍지만 픽셀별 화면 샘플링 비용 때문에 화면이 느려진다.

## 문제 코드와 개선 코드

Problem은 OnRenderImage에서 LabUltimate 셰이더를 실행한다. 셰이더는 실제로 반복적인 텍스처 샘플링을 수행한다. shaderIterations로 부하를 조절한다.

Improved는 Graphics.Blit으로 원본 화면을 출력한다. 효과가 없어지므로 동일 이미지 최적화가 아니라 시각 품질과 성능의 절충이다. 비교 구간에서는 필살기 키와 무관하게 효과를 계속 표시한다.

## 플레이와 관찰

같은 해상도와 같은 장면에서 GPU 시간·프레임 시간을 비교한다. Gfx.PresentFrame, Gfx.WaitForPresentOnGfxThread의 실제 관측 여부와 인접 프레임 관계를 확인한다. VSync/목표 FPS 제한의 정상 대기를 GPU 병목과 구분한다.

효과를 켜거나 마커가 존재한다는 것만으로 GPU 병목을 확정하지 않는다. GPU 모듈/플랫폼 도구와 해상도 민감도 등으로 확인한다. GPU 시간이 제공되지 않는 환경에서는 미확인으로 기록한다. PrepareRenderTarget이라는 이름이 반드시 나타나야 하는 것은 아니다.

2차원 블러를 분리 필터로 바꾸는 구현, Bloom/Vignetting 체인, URP 카메라 스택은 별도 확장으로 남긴다.
